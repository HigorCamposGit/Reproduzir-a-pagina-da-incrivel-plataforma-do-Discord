# Desafio: Reproduzir-a-pagina-da-incrivel-plataforma-do-Discord.

**💬 Clone do Discord - Projeto Responsivo com Flexbox e CSS Grid.**
Este projeto é um clone moderno e responsivo da landing page do **Discord**, desenvolvido como parte dos meus estudos na plataforma **DIO (Digital Innovation One)** para a **Formação CSS Web Developer**.

---

## 💡 Sobre o Projeto e Escolhas Técnicas.

Para demonstrar na prática a estilização, alinhamento e construção do layout e seja moderno com CSS3 puro, **não foram utilizadas imagens externas para o conteúdo visual principal**. `Me concentrei nas técnicas de desenvolvimento`.

Em vez de imagens estáticas, foram aplicadas **técnicas puras de desenvolvimento CSS**, tais como:
* **Gradientes Dinâmicos (`linear-gradient` e `radial-gradient`)** para simular as ilustrações e cartões artísticos originais da marca.
* **Componentes Construídos via Código**, como menus suspensos (*dropdowns*), emblemas personalizados, botões com efeitos de hover e um menu mobile compacto.
* **Iconografia Vetorial Dinâmica** utilizando o `FontAwesome` para garantir um carregamento leve e visual nítido em qualquer resolução da tela.

---

## 🚀 Tecnologias e Conceitos Aplicados.
* **HTML5 Semântico**: Uso de tags como `<header>`, `<nav>`, `<section>`, `<article>` e `<footer>` para garantir boa acessibilidade e estrutura limpa.
* **CSS3**
  * **Flexbox**: Aplicado no alinhamento do cabeçalho, distribuição do menu de navegação, alinhamento dos botões da seção e rodapé.
  * **CSS Grid**: Utilizado na estruturação das seções de conteúdo dinâmico (com colunas alternadas e seção full-width) para garantir um layout simétrico e organizado.
  * **Responsividade (`@media queries`)**: Adaptação completa do layout para dispositivos móveis, escondendo o menu extenso e ativando a navegação via botão de menu compacto.
  * **Transições e Pseudo-classes**: Animações suaves de `hover` nos botões, links e menus suspensos.

---

## 📂 Estrutura das Seções

1. **Cabeçalho Fixo**: Logótipo, tag de autoria, menus de navegação com `menus suspensos dropdowns no hover`, botão de login e `menu responsivo`.
2. **Seção Hero**: Apresentação principal da marca com botões de chamada para ação.
3. **Seções Alternadas (Grid)**: Blocos de texto e arte CSS simulada alternando posições.
4. **Seção Full-Width**: Bloco de largura total focado no destaque sobre tecnologia de áudio e vídeo.
5. **Seção Centralizada**: Bloco focado no engajamento da comunidade com dimensões ajustadas.
6. **Rodapé Personalizado**: Links para redes sociais oficiais, destaque e créditos.
